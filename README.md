# Exploratory Data Analysis 2024 — DSC530

A curated collection of EDA case studies, statistical explorations, and decision-support analyses using Python.

## Overview
This repo showcases end-to-end exploratory data analysis workflows: data loading, cleaning, descriptive statistics, visualization, and hypothesis-driven insights for decision making.

## Highlights
- Multi-source datasets: health surveys, placement data, demographic cohorts
- Statistical summaries and distribution analysis
- Interactive visualizations with Matplotlib/Seaborn
- Reproducible notebooks for weekly assignments and capstone project

## Tech Stack
Python • Pandas • NumPy • Matplotlib • Seaborn • Jupyter • ThinkStats2

## Getting Started
```bash
pip install -r requirements.txt
jupyter lab
```
